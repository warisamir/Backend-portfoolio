## Quick Start

### Run Locally
```bash
python -m http.server 8000
# or
npx http-server
```
Visit: `http://localhost:8000`

### Deploy to Vercel
```
1. Go to https://vercel.com
2. Import GitHub repository
3. Click Deploy
4. Done! Portfolio is live
```
