## 🚀 Getting Started

### **1. Clone Repository**
```bash
git clone https://github.com/warisamir/Backend-portfoolio.git
cd Backend-portfoolio
```

### **2. Run Locally**
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js
npx http-server

# Using Live Server (VS Code extension)
# Press Alt+L Alt+O
```

Visit: `http://localhost:8000`

### **3. Deploy to Vercel**
See [DEPLOYMENT_GUIDE.md](./DEPLOYMENT_GUIDE.md) for detailed instructions.

Quick start:
```bash
1. Go to https://vercel.com
2. Import GitHub repository
3. Click "Deploy"
4. Done! 🎉
```
